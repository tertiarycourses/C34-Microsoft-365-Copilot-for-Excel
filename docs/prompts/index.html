Use: Excel for Microsoft 365 or Excel for the web · Copilot (Chat only, Allow editing) · BrightPath_Candidate_Pipeline.xlsx

Instructions PDF · Lab page on GitHub · Download BrightPath_Candidate_Pipeline.xlsx

The steps
  1. Go to onedrive.com (or your SharePoint site), open or create the folder work-c34 and select Upload > Files. Upload BrightPath_Candidate_Pipeline.xlsx from this lab's data folder, then open it in Excel for the web or select Open in Desktop App. Confirm the title bar shows the cloud location and AutoSave is On, and that Formulas > Calculation Options is set to Automatic. Read the About_This_Data sheet before you prompt.
    Required state:
File      : OneDrive/work-c34/BrightPath_Candidate_Pipeline.xlsx
AutoSave  : On
Calculation Options : Automatic
Sheets    : About_This_Data | Applications | Prompt_Log
  2. Select cell A1 on the Applications sheet and press Ctrl+T (Home > Format as Table). Tick My table has headers and select OK. On the Table Design tab, set Table Name to tblApplications. Then select the Copilot button. If Copilot is unavailable, use the Troubleshooting table before continuing.
    Table name : tblApplications
Grain      : one row = one candidate application (Application_ID)
Expected   : 13 columns, 242 data rows
  3. In the Copilot pane, choose Chat only (no workbook changes). Paste the prompt below. Compare Copilot's row count and date range with the table (select the Application_ID column and read Count on the status bar). Record the prompt, what Copilot said and your check on the Prompt_Log sheet. → Prompt A
  4. Still in Chat only, ask Copilot to check data quality. It should report 2 repeated Application_IDs and Source values that are not in the canonical list on About_This_Data. Then switch to Allow editing (Edit) and ask Copilot to highlight the duplicate IDs and add a Source_Clean column. Check that no row was deleted - the table must still have 242 rows. → Prompts B, C
  5. Ask Copilot a direct question about which sources produce hires. Expand or ask Copilot to summarise any code it shows. Then verify the hires total in an empty cell on Prompt_Log with the formula below, and verify one source with COUNTIFS. Duplicate rows are Rejected applications, so they do not change the hire counts. → Prompt D
  6. Switch to Allow editing and build a review view, one change at a time. After each change, inspect the sheet and keep it or Undo. Finally apply the filter, read the visible-row count on the status bar, record it, and clear the filter so all 242 rows return. → Prompts E, F, G
  7. Complete the Prompt_Log for every prompt you ran: mode, prompt, what Copilot did, how you verified it and your decision (Keep, Revise or Undo). Save - AutoSave keeps the cloud copy current.
