Open BrightPath_Candidate_Pipeline.xlsx first. These prompts use tblApplications. Start with Prompt A: Copilot turns the raw data into the table tblApplications, which every later prompt uses. A prompt that names a different table belongs to another lab.

The steps
  1. Go to onedrive.com (or your SharePoint site), open or create the folder work-c34 and select Upload > Files.     Required state:

  3. Switch to Chat only (no workbook changes). Paste the prompt below. Copilot's row count must match the 242 rows it reported in Step 2. If Copilot already points out Source labels such as 'Linked In' or 'JobStreet ' (trailing space), note them - Step 4 checks and fixes them. You will log every prompt in Step 7. → Prompt B

Then switch to Allow editing (Edit) and ask Copilot to highlight the duplicate IDs and add a Source_Clean column. Orange means 'this ID appears more than once': each duplicate ID is coloured in both places it occurs, so you see one orange cell near the top of the table and its twin further down (press Ctrl+End to jump to the last rows). Check that no row was deleted - the table must still have 242 rows. → Prompts C, D, E, F, G
  5. Ask Copilot a direct question about which sources produce hires. Expand or ask Copilot to summarise any code it shows. Then ask Copilot (Allow editing) to add the two check formulas to a Checks sheet and compare the results with its answer. Duplicate rows are Rejected applications, so they do not change the hire counts. → Prompts H, I
  6. Switch to Allow editing and build a review view, one change at a time. After each change, look at the sheet and keep it or select Undo in the Copilot pane. Finally ask Copilot how many rows the filter shows, then ask it to clear the filter so all 242 rows return. → Prompts J, K, L, M, N
  7. Prompt_Log already lists every prompt in this lab with its step and mode. Ask Copilot to fill in what it did, how it was verified and your decision (Keep, Revise or Undo). AutoSave keeps the cloud copy current. → Prompt O
